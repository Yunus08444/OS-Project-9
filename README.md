# Симулятор управления динамической памятью (Memory Management Simulator)

Настоящий проект представляет собой учебный симулятор алгоритмов управления и распределения динамической памяти (динамических разделов и системы близнецов — Buddy System). Проект позволяет исследовать различные стратегии поиска свободных блоков, эффективность объединения смежных дыр (коалесценции) и степень фрагментации памяти.

---

## 📁 Структура проекта

* **`memsim.py`** — основная логика менеджера памяти (`MemoryManager`), реализующего стратегии распределения `first`, `best`, `worst`, а также слияние свободных блоков.


* **`buddy.py`** — реализация альтернативного алгоритма распределения памяти — двоичных близнецов (Buddy System).


* **`compare.py`** — скрипт для сравнительного анализа стратегий (`first`, `best`, `worst` с коалесценцией и `buddy`) по количеству отказов, внешней и внутренней фрагментации.


* **`run_ops1.py`** — скрипт для запуска симуляции на базовом наборе операций `ops1.txt`.


* **`gen_ops2.py`** — генератор случайной последовательности операций для нагрузочного тестирования (`ops2.txt`).


* **`ops1.txt` / `ops2.txt**` — файлы с тестовыми сценариями (команды `alloc` и `free`).



---

## ⚙️ Алгоритмы и стратегии

### 1. Стратегии поиска свободных блоков (`MemoryManager`)

В `memsim.py` реализованы три классические стратегии выбора подходящего отверстия (hole) для размещения процесса фиксированного размера:

* **`first` (First-Fit):** Выбирает первый попавшийся свободный блок, размер которого больше или равен запрашиваемому. Обеспечивает высокую скорость поиска.
* **`best` (Best-Fit):** Выбирает наименьший из подходящих блоков (минимизирует остаток). Оставляет меньше крупных дыр, но порождает много мелких неиспользуемых фрагментов.
* **`worst` (Worst-Fit):** Выбирает самый большой доступный блок. Идея в том, чтобы оставшаяся часть дыры была достаточно большой для последующих выделений.

### 2. Слияние свободных блоков (Coalescing)

При освобождении памяти (`free`) в `MemoryManager` с включенным флагом `coalesce=True` смежные свободные блоки объединяются в один крупный блок, что снижает внешнюю фрагментацию памяти.

### 3. Алгоритм близнецов (Buddy System)

Реализован в `buddy.py`. Память распределяется блоками, размер которых равен степени двойки. При выделении памяти блок при необходимости рекурсивно делится пополам, а при освобождении — сливается со своим «братом» (buddy), если тот свободен. Это минимизирует внешнюю фрагментацию за счет появления внутренней фрагментации внутри блоков-степеней двойки.

## 🚀 Инструкция по запуску

### 1. Запуск базового сценария

Для запуска демонстрации по файлу `ops1.txt` с выбором стратегии (например, `first`):

```bash
python run_ops1.py first

```

Скрипт выводит пошаговый процесс распределения памяти и итоговую статистику: объем свободной памяти, размер максимальной дыры, количество дыр и число отказов.

### 2. Сравнение всех стратегий

Для запуска сравнительного теста на нагрузочном сценарии `ops2.txt`:

```bash
python compare.py

```

Скрипт выведет сравнительную таблицу эффективности различных подходов.
